# Stratégia hry klobásky (The Sausage Game Strategy)

Tento repozitár obsahuje praktickú časť bakalárskej práce s názvom _Stratégia hry klobásky_, realizovanej na Prírodovedeckej fakulte UPJŠ v Košiciach.

This repository contains the practical part of the bachelor's thesis titled _The Sausage Game Strategy_, conducted at the Faculty of Science, Pavol Jozef Šafárik University in Košice.

---

## Štruktúra repozitára / Repository Structure

**SK:** Aktuálna verzia aplikácie je v adresári **the-sausage-game-v2**, ostatné slúžia iba na archívne účely.

**EN:** The current version of the application is located in the **the-sausage-game-v2** directory; others are for archival purposes only.

## Inštalácia a spustenie / Installation and Running

**SK:** Pre spustenie aplikácie nie sú potrebné žiadne dodatočné inštalácie a závislosti. Podporované sú systémy Windows, macOS (Intel aj Apple Silicon) a Linux (64-bitové verzie).

1. Prejdite do sekcie **Releases** v tomto repozitári.
2. Stiahnite si archív (.zip) pre váš operačný systém.
3. Extrahujte stiahnutý súbor.
4. Hru spustíte dvojitým kliknutím na spustiteľný súbor v danom adresári.

**EN:** No additional installations or dependencies are required to run the application. Windows, macOS (both Intel and Apple Silicon), and Linux (64-bit versions) are supported.

1. Go to the **Releases** section of this repository.
2. Download the archive (.zip) for your operating system.
3. Extract the downloaded file.
4. Launch the game by double-clicking the executable file in the directory.

## Upozornenie / Warning

**SK:** Algoritmus prehľadáva rozsiahly herný strom v reálnom čase, na zariadeniach so slabším výpočtovým výkonom sa to môže odzrkadliť na jeho rýchlosti. Pri použití štandardného stolového počítača alebo laptopu by však chod aplikácie mal byť bezproblémový.

**EN:** The algorithm explores an extensive game tree in real time; on devices with lower computing power, this may affect its speed. However, the application should run smoothly on a standard desktop or laptop.
