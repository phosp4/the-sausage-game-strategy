# Stratégia hry klobásky / The Sausage Game Strategy

> **Language / Jazyk:** [English version](#english) | [Slovenská verzia](#slovenčina)

## Slovenčina

Tento repozitár obsahuje praktickú časť bakalárskej práce s názvom *Stratégia hry klobásky*, realizovanej na Prírodovedeckej fakulte UPJŠ v Košiciach.

### Štruktúra repozitára
Aktuálna verzia aplikácie je v adresári **the-sausage-game-v2**, ostatné slúžia iba na archívne účely.

### Inštalácia a spustenie
Pre spustenie aplikácie nie sú potrebné žiadne dodatočné inštalácie a závislosti. Podporované sú systémy Windows, macOS (Intel aj Apple Silicon) a Linux (64-bitové verzie).

1. Prejdite do sekcie **Releases** v tomto repozitári.
2. Stiahnite si archív (.zip) pre váš operačný systém.
3. Extrahujte stiahnutý súbor.
4. Hru spustíte dvojitým kliknutím na spustiteľný súbor v danom adresári.

### Upozornenie
Algoritmus prehľadáva rozsiahly herný strom v reálnom čase, na zariadeniach so slabším výpočtovým výkonom sa to môže odzrkadliť na jeho rýchlosti. Pri použití štandardného stolového počítača alebo laptopu by však chod aplikácie mal byť bezproblémový.

## English

This repository contains the practical part of the bachelor's thesis titled *The Sausage Game Strategy*, conducted at the Faculty of Science, Pavol Jozef Šafárik University in Košice.

### Repository Structure
The current version of the application is located in the **the-sausage-game-v2** directory; others are for archival purposes only.

### Installation and Running
No additional installations or dependencies are required to run the application. Windows, macOS (both Intel and Apple Silicon), and Linux (64-bit versions) are supported.

1. Go to the **Releases** section of this repository.
2. Download the archive (.zip) for your operating system.
3. Extract the downloaded file.
4. Launch the game by double-clicking the executable file in the directory.

### Warning
The algorithm explores an extensive game tree in real time; on devices with lower computing power, this may affect its speed. However, the application should run smoothly on a standard desktop or laptop.
